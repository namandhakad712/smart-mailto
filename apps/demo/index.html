Why smart-mailto?

        

          

            
🌍

            
Geo-Aware by Default

            

              Uses
              Intl.DateTimeFormat
              to detect region in <1ms. No IP APIs, no GDPR drama. Yandex for Russia, Naver for
              Korea, Yahoo Japan for Japan.
            

          

          

            
⚡

            
One Line of Code

            

              Drop
              initSmartMailto()
              at your app root. Every existing
              <a href="mailto:...">
              on your site just works. Zero HTML changes.
            

          

          

            
📦

            
Zero Dependencies

            

              No lodash, no axios, no moment. The entire engine is pure TypeScript using only
              browser-native APIs.
            

          

          

            
🎨

            
Headless Ready

            

              Bring your own CSS via
              classNames. Full Tailwind compatibility. Or use the gorgeous built-in glassmorphism theme.
            

          

          

            
📱

            
Mobile Smart

            

              Detects iOS and Android and auto-promotes the native Mail App to the top of the list,
              where it belongs.
            

          

          

            
♿

            
WCAG 2.1 AA

            

              Focus trap, ESC key close, ARIA roles, keyboard navigation. Accessible out of the box,
              no extra config.
            

          

          

            
🔒

            
Privacy First

            

              Zero external requests. Only stores a 5-char provider ID in localStorage after
              explicit user choice. No cookies. No tracking.
            

          

          

            
🧩

            
Framework Wrappers

            

              First-class React, Vue 3, and Svelte packages. Angular coming in v2. The core works
              with any framework or none.
            

          

          

            
🔗

            
Full RFC 6068 Parser

            

              Parses
              cc,
              bcc,
              subject,
              body.
              Works with encoded characters, multiple recipients, and all edge cases.
            

          

        

      


      
      

        
Global provider coverage
